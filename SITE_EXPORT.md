# PEHRAN static site export

This repository contains the browser-ready static export of the PEHRAN Kashmiri craftsmanship storefront served by the Manus preview URL. The export includes the HTML shell, compiled JavaScript and CSS, favicon, and all first-party image assets referenced by the deployed bundle.

The files are ready to publish from the repository root with GitHub Pages. Product data has an embedded client-side fallback in the compiled bundle, so the catalog remains usable without the original preview API.
